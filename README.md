# Cyber Pong Arena - 2D Single-Player Pong

A responsive, cyberpunk-styled 2D Pong game created inside a single HTML file with pure vanilla JavaScript and the HTML5 Canvas API without any external dependencies or physics engines.

## Features
- **Controls & Input**: Smooth paddle movement using W/S, Up/Down arrow keys, or mobile touch-and-drag.
- **Physics**: Manual velocity updates (dx, dy) with wall reflections.
- **Dynamic Angles (Bonus)**: Trajectory calculation based on relative impact offset from paddle center.
- **Realistic Bats**: Table tennis bats with wood plies, rubber pads, and kinetic tilt response.
- **Game Modes & Power-Ups**: 3 difficulty levels (Easy, Medium, Hard), speed surges, paddle lengtheners, and AI freeze pulses.
- **Responsive Viewport**: Automatically scales across monitors and mobile screens.

## How to Play
Open `index.html` in any web browser, enter your callsign, select difficulty, and click Launch Match.
